Folder AMIGO2 contains the neccesary files to run the practical identifiability test. To use them first run install AMIGO2. Then, run "model_data_generator.m" to generete the data, the sampling times, initial states and paramenters can be modified. 
Finally, run "model_run_RIdent.m" to get the practical identifiability results.

Folder Results contains the results already obtained.
